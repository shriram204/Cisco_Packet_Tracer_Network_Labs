# Cisco_Packet_Tracer_Network_Labs
This repository contains my hands-on networking labs and practice exercises completed using **Cisco Packet Tracer** as part of my **CCNA and Computer Networking learning**.

The labs cover important networking concepts such as routing, switching, VLANs, ACLs, NAT, BGP, and network security.

---

## 📚 Labs Covered

| Lab | Concept |
|---|---|
| ACL | Access Control List |
| BGP | Border Gateway Protocol |
| EIGRP | Enhanced Interior Gateway Routing Protocol |
| Extended ACL | Extended Access Control List |
| LAN | Local Area Network |
| PAT | Port Address Translation |
| Standard ACL | Standard Access Control List |
| Static & NAT | Static Routing and Network Address Translation |
| VLAN | Virtual Local Area Network |

---

## 🛠️ Tools Used

- **Cisco Packet Tracer**
- **Cisco IOS CLI**
- **Windows**
